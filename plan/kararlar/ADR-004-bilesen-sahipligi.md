# ADR-004 · İş bölümü modeli: görev değil bileşen/modül sahipliği

**Tarih / onay:** 2026-09-24; eşleme 2026-09-25 ekip onayı

- **Ne (yön):** Herkes AI agent'la kod yazacağı için kişiler arası çakışmayı önlemek adına iş bölümü görev bazlı değil, uygulamanın bileşenleri/modülleri bazında yapılacak. Ayrıntılı model (modül haritası, sözleşmeler, repo, PR/CI, agent talimat dosyaları, board) `arastirma/08-ekip-calisma-modeli.md` sonrası netleşecek.
- **Araştırma (2026-09-24):** `arastirma/08-ekip-calisma-modeli.md` → bileşen sahipliği + contract-first + CI kapıları (Spring Modulith verify, ArchUnit, CODEOWNERS, oasdiff, gitleaks); tek monorepo; kök `AGENTS.md` tek kaynak + modül `AGENTS.md`; ~~kökte `CLAUDE.md` yok~~ → **düzeltildi, ADR-013:** kökte `CLAUDE.md` = `@AGENTS.md` importu (ekip makinesindeki Claude Code 2.1.183 AGENTS.md'yi doğrudan okumuyor; import tüm sürümlerde çalışır); GitHub Projects; trunk-based, PR = tek modül; 2 haftalık sprint danışmana hizalı. Kişi eşlemesi Levent kararı bekliyor. *(→ eşleme 2026-09-25'te yapıldı, aşağıda; board → ADR-005 Azure Boards)*
- **Eşleme (2026-09-25):** Levent → platform/mimari (repo, CI, sözleşmeler, AGENTS.md), Hane Planlama Motoru, asistan orkestrasyonu, Gizlilik Kapısı, karar kaydı + gözlemlenebilirlik, E1/E2 · Hilal → kural motoru, alerjen verisi + altın set, hane/kimlik/rıza, katalog/fiyat, kiler backend, öneri, admin backend · Ozan → mobil, web ve admin arayüzleri (üretilmiş API istemcisi + ortak tasarım sistemi üstünde), tarif içerik küratörlüğü, vision demo şeridi. Her modülün vekili var; yük ~18 Aralık civarında yeniden dengelenir.
- **Neden:** her modülün tek sahibi olsun, farklı agent'lar (Claude Code / Codex / Antigravity) aynı dosyalara dokunmasın; çapraz bağımlılık sözleşmelerle; kritik kurallar (safety, privacy) testle korunur.
