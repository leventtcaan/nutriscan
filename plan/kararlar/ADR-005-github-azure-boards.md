# ADR-005 · Araçlar: GitHub

**Tarih / onay:** kod) + Azure Boards (planlama) (2026-09-25, ekip

- **Ne:** Kod GitHub private repo (Student Pack Pro → CODEOWNERS + branch koruması); planlama Azure DevOps Boards, Scrum şablonu (PBI/Task/Bug/Sprint, backlog, burndown), commit/PR'da `AB#<id>`; agent erişimi resmi Azure DevOps MCP sunucusu.
- **Neden:** ekip geçen yıl da bu düzenle çalıştı; ilk 5 kullanıcı ücretsiz; PBI/sprint düzeni hazır; üç agent MCP ile okuyup yazabiliyor.
- **Alternatif:** GitHub Projects · Contabo VPS'e Plane/Taiga. **Neden değil:** yerleşik backlog/PBI yok · bakım/güvenlik yükü.
