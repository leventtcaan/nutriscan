# ADR-012 · Çalışma akışı + board'un tek kaynaktan üretilmesi

**Tarih / onay:** 2026-09-27, taslak — ekip onayı A0.1 ile

- **Ne:** `plan/calisma-akisi.md` standardı: Azure Boards'ta Epic = aşama, Feature = takvim satırı, PBI = 0,5–2 günlük tek modül/tek PR işi; 2 haftalık sprint (Pazartesi–Pazar), sprint sonu Cuması = Meeting Record teslimi; DoR/DoD; dal `<modül>/AB<id>-…`, `Fixes AB#<id>`; her PBI'ın standart agent promptu. PBI metinlerinin tek kaynağı `plan/board/pbi.yaml`; `plan/board/board_uret.py` takvimle birleştirip Azure CSV'si, backlog özeti ve promptları üretir, bağımlılık tarihi ve kişi başı kapasiteyi denetler.
- **Neden:** üç farklı agent'la çalışan ekipte "herkesin kafasına göre" iş tanımı ve prompt olmasın; takvim–board–prompt tutarsızlığını betik yakalasın (ilk koşuda 5 bağımlılık tarihi hatası ve Sprint 0'da Levent 43 / Ozan 17 Effort aşımı yakaladı → takvim v1.5 ile dengelendi).
- **Alternatif:** board'u elle doldurmak · GitHub Projects (08 raporu). **Neden değil:** elle kopyalama kayar ve denetlenmez · ADR-005 Azure Boards seçti.
- **Onay (2026-09-27, Levent):** Sprint 0 kapasitesi L20/H14/O14 · Hazırlıkta üç iskelet işinin öne çekilmesi · repo + board en geç 10 Ekim · vekil tablosu. Aşama 2 PBI'ları eklendi (toplam 65 PBI, 53 prompt; Sprint 1–4 yükü kişi başı ≤13).
- **Azure durumu (2026-09-27):** board = `dev.azure.com/hilalhocaoglu20/NutriScan` (organizasyon sahibi Hilal; Levent erişimli). Geçen yılın 92 iş öğesi özetlenip (`plan/board/arsiv/eski-board-2026-bahar.md`) silindi → çöp kutusunda, geri alınabilir. Hilal projeyi Scrum'dan türetilmiş **"NutriScan Scrum"** sürecine taşıdı (27 Eyl; geçiş için özel "Issue" tipi süreçte duruyor, kullanılmıyor). Projede geçen yılın 4 Azure Repos deposu duruyor (dokunulmadı; commit'li SMTP sırrı sorusu DURUM'da açık). **Kurulum (27 Eyl, REST + arayüz, doğrulandı):** sprintler Hazırlık (28 Eyl–18 Eki), Sprint 0–4 (19 Eki–27 Ara, 2 haftalık, haftanın 7 günü çalışma günü); 16 alan yolu (platform, data, research, backend\{9 modül}, apps\{mobile, web}); takım: alan alt dalları dahil, Epic seviyesi görünür, Bug'lar gereksinim gibi; takıma Levent + Ozan eklendi (3 üye). 159 öğe yüklendi: 8 Epic → 65 Feature → 65 PBI (53'ünün açıklamasında tam agent promptu, AB# numaralı) + 21 ekip Task'ı (ekip PBI'larında kişi başı pay); hepsi kişiye atanmış, New durumunda, bildirim kapalı.
