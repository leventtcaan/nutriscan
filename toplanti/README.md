# Toplantı kayıtları

## Güncel başvuru

- Güncel kapsam, kararlar ve kod/veri durumu için [mimari karar belgesi](../docs/mimari-karar-belgesi.md) tek doğruluk kaynağıdır.
- Tarihli ekip mesajları ve görüşme hazırlıkları geçmişteki taslakları gösterir; içlerindeki “sonraki işler” bugünkü görev durumu değildir.
